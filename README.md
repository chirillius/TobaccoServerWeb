# TobaccoServerWeb

Сервис магазина: конфигурация камер и зон, запуск заданий аналитики, фиксация нарушений и работа с видеоархивом. Использует SQL Server и общую библиотеку TobaccoEntities.

Настройка Windows, сборка, инициализация базы и совместимость многоугольных зон описаны в [docs/README.md](docs/README.md).
